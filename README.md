Solara Bay is a 2D top-down open-world crime game that plays offline in a desktop browser: explore a sun-soaked coastal city on foot and by car, steal cars, dodge the Solara police as the wanted level rises, and run three story missions for fixer Delia Crane — with traffic, pedestrians, combat, a minimap HUD, and a localStorage save.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with W A S D, steal a car with E, shoot with the mouse, punch with F, save with L, pause with P.
